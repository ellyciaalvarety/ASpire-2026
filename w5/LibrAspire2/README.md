# 📚 LibrAspire Laravel

LibrAspire Laravel adalah aplikasi manajemen perpustakaan berbasis web yang dibangun menggunakan framework Laravel dan database SQLite. Sistem ini memiliki fitur autentikasi dan pembagian hak akses berdasarkan role pengguna, yaitu Superadmin, Admin, dan Member.

## 🚀 Features

### 🔐 Authentication
- Login
- Register
- Role-based access control
- Session management

### 👑 Superadmin
- Mengelola data user
- Mengatur role Admin dan Member
- Monitoring aktivitas sistem

### 📖 Admin
- CRUD data buku
- Mengelola status peminjaman buku

### 👤 Member
- Melihat daftar dan detail buku
- Mengajukan peminjaman buku
- Mengakses dashboard member
